# repo-rehab

`repo-rehab` is the working repository for a local-first forensic Git tool.

Its v0.1 promise is **preserve + compare + prove + plan**: preserve uncertain
repositories without checkout or execution, prove their all-ref Git
relationships, and produce a collision-safe archival plan with inspectable
evidence.

Status: **private pre-release; v0.1 under development**.

The working repository name is an implementation namespace, not a final brand.
